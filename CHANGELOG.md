# Changelog

Atlasium uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-04

First stable release for World of Warcraft 3.3.5a (WotLK, interface 30300).

### Available

- Drag and zoom the world map, with quest icons kept at a readable size.
- Show unexplored world map terrain with fog clearing.
- Open Atlasium from a movable minimap button.
- Zoom the minimap with the mouse wheel.
- Configure features in a native settings dialog or Interface Options.
- Use English or Brazilian Portuguese text.
- Enable experimental minimap terrain tiles.

### Installation

Download **Atlasium-v1.0.0.zip** from this release and extract it.
Copy its `Atlasium` folder into `<WoW folder>\Interface\AddOns\`.
The archive includes player Markdown documentation in English and Brazilian Portuguese, and the license.

### Limitations

Custom minimap tiles are experimental. Outdoor rendering is checked; some in-game field checks remain open.
Map notes, Questie and TomTom integration, and party sharing are planned for future releases.
