# Party integration

> Planned. None of this is built yet.

Atlasium will talk to other party members who also have it installed, using add-on channels.
These are hidden from the chat window, so no one has to type anything.

## What you will be able to do

- **Share waypoints**: send a waypoint to the whole party.
- **Leader-controlled tracking**: the party leader can change the TomTom waypoint for every
  member, so everyone follows the same route.
- **Ping**: point at a spot on the map to get your group's attention.
- **Share notes**: see the same map notes as the rest of your party.

## Requirements

Every member who wants to take part needs Atlasium. Members without it are not affected and
see nothing. TomTom is needed only for the shared tracking feature.
