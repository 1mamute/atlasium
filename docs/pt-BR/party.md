# Integração com o grupo

> Planejado. Estes recursos ainda não foram implementados.

O Atlasium se comunicará com outros membros do grupo que também tenham o add-on instalado.
Ele usará canais de add-ons, que não aparecem no chat. Ninguém precisará digitar mensagens.

## O que será possível fazer

- **Compartilhar pontos de destino**: envie um ponto para todo o grupo.
- **Rastreamento controlado pelo líder**: o líder poderá alterar o destino do TomTom para todos
  os membros, para que todos sigam a mesma rota.
- **Ping**: indique um lugar no mapa para chamar a atenção do grupo.
- **Compartilhar notas**: veja as mesmas notas no mapa que o restante do grupo.

## Requisitos

Todos os membros que quiserem participar precisarão do Atlasium.
Membros sem o add-on não serão afetados e não verão as mensagens.
O TomTom será necessário apenas para o rastreamento compartilhado.
